先直覺，再公式

1先認得加分與扣分

發射功率 Pt、發射增益 Gt、接收增益 Gr往上加；FSPL、雜項損耗與極化損耗往下扣。dB 尺度讓乘除變成加減。

2先問「還剩多少餘裕」

接收功率高於接收門檻的差值叫鏈路餘裕。餘裕越大，面對遮蔽、姿勢與環境變動通常越安心。

一步：看功率

0 dBm = 1 mW；30 dBm = 1 W。dBm 是絕對功率。

二步：看天線

dBi 描述相對理想等向性天線的增益，是方向集中能力。

三步：看傳播

在自由空間中，距離加倍通常讓接收功率約下降 6 dB。

公式急救包：先對單位，再按順序加減

線性式適合理解物理，dB 式適合工程記帳。兩者描述同一件事。

單位清楚

dBm 與 dBi

PdBm = 10 log10(P/1 mW)GdBi = 10 log10(Glinear)

dBm 以 1 mW 為基準；dBi 以理想等向性天線為基準。

波長與自由空間路徑損耗

λ = c/f [m]FSPL = 20 log10(4πR/λ) [dB]FSPL = 32.44 + 20 log fMHz + 20 log Rkm

第二式只能搭配 f 用 MHz、R 用 km；單位換錯會差很多。

線性極化失配

PLF = cos²(Δψ)，Lpol = −10 log10(PLF) [dB]

Δψ = 0° 時完全對準；45° 時 PLF = 0.5，功率損耗約 3 dB；90° 為理想正交。

完整 Friis 與 dB 記帳

Pr = PtGtGr[λ/(4πR)]²PLF [W]Pr = Pt + Gt + Gr − FSPL − Lmisc − Lpol

使用 Friis 時要確認自由空間、遠場、阻抗匹配與增益定義等假設。

常見迷思：看見錯法，就更容易記住正法

三個檢查點

迷思 1：dBm 與 dBi 可以互換

dBm 是功率，dBi 是天線增益。它們在鏈路預算中可以相加減，但物理意義不同。

迷思 2：距離加倍只少 3 dB

自由空間接收功率與 1/R² 成正比，因此距離加倍是 1/4，約少 6.02 dB。

迷思 3：Friis 可代表所有環境

牆壁、地面反射、多路徑與天線附近物體會改變結果；本頁先建立自由空間基準。
