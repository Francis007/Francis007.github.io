📐 全篇座標與符號約定： 負載在右端、電源在左端；位置座標 z′ 從負載往電源量（z′ = 0 就在負載上）。 Z₀＝特性阻抗 (characteristic impedance)、Z_L＝負載阻抗、Γ＝電壓反射係數 (voltage reflection coefficient)、 S 或 SWR＝駐波比 (standing-wave ratio)、Z_in＝輸入阻抗 (input impedance)、 z = Z/Z₀＝正規化阻抗 (normalized impedance)、βz′＝電長度 (electrical length)。 本章全部假設無損耗線 (lossless line)：γ = jβ、α = 0、Z₀ 為實數。

① 傳輸線上的電壓駐波 voltage standing wave

👀 你現在在看什麼：一條特性阻抗 Z₀ 的無損耗傳輸線，右端接負載 Z_L = R_L + jX_L。 橘色是入射波（往右、往負載跑）、 紫色是反射波（往左、往電源跑）、 紅色是兩者疊加後的瞬時電壓 v(z′,t)、 深青色是包絡 ±|V(z′)|，也就是「駐波型態」。
💡 生活類比：跳繩
你甩繩子，波往前跑到另一端。另一端被牆綁死（短路）→ 波原封不動彈回來，跟去的波疊在一起，繩子上就出現幾個永遠不動的點（節點）和幾個甩得最兇的點（腹點）。 另一端交給一個跟你同步的人接住（匹配）→ 能量被接走，沒有東西彈回來，繩子上看不到節點，只有一路往前跑的波。 傳輸線一模一樣，只是「繩子」換成電壓。

🎯 該注意哪裡：
  • 相鄰兩個 V_max（或兩個 V_min）相距 λ/2，而 V_max 與最近的 V_min 相距 λ/4。這是本章最常被考的距離關係——駐波看的是振幅絕對值，一個週期裡過零兩次，所以間距是半波長不是一個波長。
  • 把 X_L 拉離 0 → V_max 的位置整排平移，因為 Γ 的相角 θ_Γ 變了，而 z′max = θ_Γλ/(4π)。SWR 只由 |Γ| 決定，跟相角無關：拉 X_L 時 SWR 和包絡的胖瘦會變，但「幾個 max、間距多少」永遠不變。
  • 打開「電流包絡」：電壓最大的地方電流最小、電壓最小的地方電流最大。V 與 I 的包絡剛好錯開 λ/4。這就是為什麼 V_min 處的阻抗 Z = V/I 最小（＝ Z₀/S），V_max 處最大（＝ SZ₀）。
  • 把 R_L 調到剛好等於 Z₀、X_L = 0 → 紫色反射波整個消失，包絡變成兩條水平線，SWR = 1。這叫阻抗匹配 (matched)。
  • 切到「📏 只看包絡」：畫面停下來，你就能專心讀 V_max / V_min 的位置——常見的是這張靜態包絡圖，不是動畫。
本模式使用的式子
Γ = (Z_L − Z₀)/(Z_L + Z₀) = |Γ|ejθΓ　　S = SWR = (1 + |Γ|)/(1 − |Γ|)　　|Γ| = (S − 1)/(S + 1)
V(z′) = V₀⁺(ejβz′ + Γe−jβz′)　　I(z′) = (V₀⁺/Z₀)(ejβz′ − Γe−jβz′)
|V(z′)| = |V₀⁺|·|1 + Γe−j2βz′|　　V_max = |V₀⁺|(1+|Γ|)　　V_min = |V₀⁺|(1−|Γ|)
z′max = (θΓ + 2nπ)λ/(4π)　　z′min = z′max ± λ/4　　（n = 0, 1, 2, …）
Z_in(z′) = Z₀ (Z_L + jZ₀tan βz′)/(Z₀ + jZ_L tan βz′)　　β = 2π/λ
⚠️ 畫面上的注意事項：橫軸是位置 z′（空間），不是時間。畫面上「跑」的紅線是同一條線上的電壓分布隨時間變化的樣子。深青色的包絡完全不動——這就是「駐波 standing wave」的意思：波形的形狀站著不動，只有高度在原地上下呼吸。

🤔 引導問題（先自己想，再展開）

SWR → ∞（畫面顯示 ∞，包絡的最小值掉到 0）。

算一次就懂：Z_L = j50、Z₀ = 50 → Γ = (j50 − 50)/(j50 + 50)。分子與分母的大小完全一樣（都是 50√2），只差在相角，所以 |Γ| = 1。代進 S = (1+1)/(1−1) = 2/0 → ∞。

物理上：電抗元件（純電感、純電容）不消耗任何實功率，它只把能量暫存起來再全部吐回去。既然一點功率都吃不掉，入射的功率只能百分之百反射。開路和短路也是同樣的道理（|Γ| = 1）。

差別在哪：短路的 Γ = −1（θ_Γ = 180°）、開路的 Γ = +1（θ_Γ = 0°）、純電抗的 |Γ| = 1 但相角是其他角度——所以三者的駐波「胖瘦一樣（都是最極端）」，只是節點的位置被平移。你可以拉 X_L 滑桿直接看節點整排滑動。

R_L > Z₀ → 負載處是 V_max。因為 Γ = (100−50)/(100+50) = +1/3 是正實數，θ_Γ = 0°，所以 z′max = 0。

R_L < Z₀ → 負載處是 V_min。Γ = (25−50)/(25+50) = −1/3 是負實數，θ_Γ = 180°，代進 z′max = θ_Γλ/(4π) = λ/4，所以最大值退到 λ/4 處，負載處反而是最小值。

這正是這裡的關鍵。實驗上反過來用也成立：只要量到「第一個電壓最小值出現在負載上」，就知道 R_L < Z₀；再由 SWR 算出 R_L = Z₀/S。（R_L > Z₀ 時則是 R_L = S·Z₀。）

動手試：按「純電阻 100 Ω」看一次，再把 R_L 滑桿拉到 25 Ω，盯著 z′ = 0 那一端的包絡從「鼓起來」變成「掐下去」。

ℓ = λ/2（或任何 nλ/2）時，Z_in = Z_L，原封不動。因為 tan βℓ = tan π = 0，代進 Z_in = Z₀(Z_L + jZ₀·0)/(Z₀ + jZ_L·0) = Z_L。這叫半波長線 (half-wave line)。

ℓ = λ/4 時，Z_in = Z₀²/Z_L（tan βℓ → ∞，取極限）。這是四分之一波長轉換器 (quarter-wave transformer)，模式④ 會整段玩它。注意它會把大阻抗變小、小阻抗變大——是個「阻抗翻轉器」。

中間的長度則在複數平面上繞：Z_in 隨 ℓ 週期性變化，週期是 λ/2 不是 λ。這件事在史密斯圖上就是「轉一整圈＝走了半個波長」（模式③）。

只有匹配時例外：Z_L = Z₀ 的話，不管線多長 Z_in 永遠是 Z₀。把「快速情境」按到「匹配」再拉線長滑桿，Z_in 那格完全不動。

🎯 該注意哪裡：
  • 開路：負載端電流被切斷（I = 0），所以電壓在那裡疊到最大。Γ = +1，第一個節點退到 z′ = λ/4。
  • 短路：負載端被銅線接死（V = 0），電壓在那裡永遠是零。Γ = −1，第一個節點就在 z′ = 0。
  • 兩者的節點剛好差 λ/4 —— 把「λ/4 對照尺」打開，看那條連接兩個節點的虛線。這是實驗室用來判斷「線到底是開路還是短路」的標準手法。
  • 匹配：Γ = 0，包絡是兩條平的直線，SWR = 1，沒有任何節點。線上任何一點看進去的阻抗都是 Z₀（等同於「線被延伸到無限遠」）。
  • 純電抗：|Γ| = 1，胖瘦跟開路／短路一模一樣（一樣是 SWR = ∞），但節點的位置被平移到其他角度——這證明了「SWR 管胖瘦，θ_Γ 管位置」。

💡 為什麼工程上要在乎？短路截線 (short-circuited stub) 只要換長度就能當成任何電感或電容——UHF 頻段做不出好的集總元件，就用一段線代替（可視為電路元件的傳輸線）。而且短路端比開路端好做：開路端會往外輻射、還會受手指靠近影響，短路端焊一顆過孔就搞定，這就是「為何常用短路截線」的原因。

🤔 引導問題

看節點的位置。SWR 只告訴你 |Γ| 有多大，節點位置才告訴你 θ_Γ 是多少。

  • 短路：θ_Γ = 180° → 第一個 V_min 就在負載上（z′ = 0），然後每 λ/2 出現一次：0、0.5λ、1.0λ…
  • 開路：θ_Γ = 0° → 第一個 V_min 在 z′ = λ/4，然後 0.75λ、1.25λ…

所以量到節點在哪，就把 Γ 的大小和相角都定死了，Z_L 也就算得出來（這套測量法正是由此而來）。

動手試：把主角切到「開路」記下第一個 V_min 位置，再切到「短路」比較——差距永遠是 0.25λ。

代公式：短路線 Z_in = jZ₀ tan βz′。當 z′ = λ/4 時 βz′ = (2π/λ)(λ/4) = π/2，tan(π/2) → ∞，所以 Z_in → ∞ ＝ 開路。

看畫面：切到短路那一列，把參考線滑桿移到 z′ = 0.25λ。你會看到那裡剛好是電壓腹點（V_max）——電壓最大、電流為零，V/I → ∞，這正是「開路」的定義。

白話：λ/4 的線是個「阻抗翻轉器」，它把短路翻成開路、把開路翻成短路、把 Z_L 翻成 Z₀²/Z_L。這也是模式④ 四分之一波長轉換器能成功的原理。

常見誤解：這只在那一個設計頻率成立。頻率變一倍，λ 減半，同一段實體長度就變成 λ/2，短路又變回短路了。

包絡是平的，但電壓不是處處相同。包絡平代表每一點的振幅一樣大；瞬時值仍然是一個往前跑的行進波，各點的相位不同（打開「顯示瞬時波形」看紅線在跑）。

換句話說：|V(z′)| = |V₀⁺| 為常數，但 V(z′) = V₀⁺ejβz′ 的相角隨 z′ 線性增加。相位差就是電長度 βz′。

所以線還是要管：兩條並聯的饋線若長度差半個波長，訊號到達時會反相互相抵銷；高速數位電路的等長布線 (length matching) 管的就是這件事。匹配消掉的是反射，不是傳播延遲。

③ 互動史密斯圖 Smith chart

👀 你現在在看什麼：史密斯圖就是反射係數 Γ 的複數平面（單位圓內），上面再疊印正規化阻抗 z = Z/Z₀ 的格線。 深青色的圓是等電阻圓 r = 常數、 紅色的弧是等電抗圓 x = 常數。 紫色那顆大點就是你的負載 z_L——用滑鼠或手指直接拖它，或用下面的 R、X 滑桿輸入。 橘色虛線圓是等 SWR 圓， 藍色那顆點是往電源走 d 距離後看到的 Γ_in / z_in。
🔑 一句話說穿史密斯圖：它把「阻抗 Z」和「反射係數 Γ」用同一張圖畫在一起， 靠的是雙線性映射 Γ = (z−1)/(z+1) 與其反函數 z = (1+Γ)/(1−Γ)。 於是「沿線移動」這件本來要算 tan 的麻煩事，變成「在圖上繞圈圈」——圓規量一量就有答案，這是還沒有計算機的年代發明它的原因。

示範題：Z₀ = 50 Ω 的無損耗線，接上 Z_L = 25 + j50 Ω，線長 ℓ = 0.125λ。求 Z_in。 按下面五個步驟按鈕，畫面會一步一步帶你做。
👉 目前狀態：還沒開始。按「步驟 1」。
🎯 該注意哪裡：
  • 圖上永遠是正規化阻抗 z，不是 Z。畫進去前要除以 Z₀，讀出來後要乘回 Z₀。這是初學最常掉的坑，畫面上「z_L」和「Z_in」兩格特地分開顯示就是要你養成習慣。
  • 上半圓 = 電感性（x > 0）、下半圓 = 電容性（x < 0）、中線 = 純電阻。拖著點上下移動，看 X_L 的正負跟著變號。
  • 往電源方向移動 = 順時針轉。轉的角度是 2βd（不是 βd！），所以走 λ/2 就轉滿 720°/2 = 360°，剛好一整圈——這就是「半波長線阻抗不變」在圖上的樣子。
  • |Γ| 在轉動時完全不變（無損耗線），所以那顆點只會沿著同一個橘色圓跑。SWR 也因此全線相同。
  • 與正實軸的交點 = V_max 且 z = S（等於 SWR 的數值）；與負實軸的交點 = V_min 且 z = 1/S。拖到讓橘圓交在 r = 2 的地方，去看 SWR 那格是不是 2。
  • 打開「導納點」：y = 1/z 就是把點繞圓心旋轉 180°（因為 y = (1−Γ)/(1+Γ)，等價於 Γ → −Γ）。模式④ 的單截線匹配全程都在導納圖上做。
史密斯圖的數學骨架（本模擬就是照這幾條式子畫的）
Γ = (z − 1)/(z + 1)，z = r + jx　　⇔　　z = (1 + Γ)/(1 − Γ)
等電阻圓 r = 常數：圓心 ( r/(1+r) , 0 )，半徑 1/(1+r)
等電抗圓 x = 常數：圓心 ( 1 , 1/x )，半徑 |1/x|（只取單位圓內的弧）
三個必背特殊點：z = 0（短路）→ Γ = −1，最左邊；z → ∞（開路）→ Γ = +1，最右邊；z = 1（匹配）→ Γ = 0，正中央
沿線移動：往電源走 d → Γ(d) = Γ_L e−j2βd（順時針轉 2βd）；往負載走則是逆時針
與實軸交點：右交點 z = S = SWR（V_max 處）；左交點 z = 1/S（V_min 處）
⚠️ 三個最容易畫錯的地方
① 忘記除以 Z₀：Z_L = 100 + j50 Ω 在 Z₀ = 50 的圖上是 z = 2 + j1，不是「100 + j50」。史密斯圖上根本沒有「Ω」這個單位。
② 轉的角度用成 βd：正確是 2βd，因為反射波要來回走兩趟。d = λ/8 → 2βd = 90°，不是 45°。
③ 轉錯方向：往電源（wavelengths toward generator）＝順時針；往負載＝逆時針。外圈刻度上有標，別憑感覺。

🤔 引導問題

代表 r = 0，也就是完全不吃實功率的負載：純電抗、短路、或開路。單位圓邊界就是 r = 0 那個圓（圓心 (0,0)、半徑 1），你可以在畫面上驗證：拖到邊界時 R_L 那格會變成 0。

SWR = ∞。因為 S = (1+|Γ|)/(1−|Γ|)，|Γ| = 1 時分母為 0。畫面上會顯示 ∞ 並跳出紅色警告標籤。

能量觀點：|Γ|² = 1 表示入射功率 100% 被彈回來，負載一瓦都沒吃到。所以「史密斯圖的外圈」＝「全反射的世界」，越靠近中心反射越少，圓心就是完美匹配。

d = 0.25λ → 轉 180°（半圈）；d = 0.5λ → 轉 360°（整整一圈，回到原點）。

算給你看：轉動角 = 2βd = 2·(2π/λ)·d = 4πd/λ。代 d = λ/4 → 4π/4 = π = 180° ✓；代 d = λ/2 → 2π = 360° ✓。

兩個立刻能用的結論：

  • d = λ/2 → 轉一整圈 → Z_in = Z_L（半波長線阻抗不變）。
  • d = λ/4 → 轉半圈 → 點跑到圓心正對面 → z_in = 1/z_L，還原後 Z_in = Z₀²/Z_L（四分之一波長轉換器）。

動手試：按「例題 z = 0.5 + j1」，再把 d 拉到 0.25λ，看 z_in 那格是不是變成 1/(0.5+j1) = 0.4 − j0.8。

會跑掉。拉 Z₀ 滑桿試試看：R_L、X_L 的歐姆數字沒變，但點的位置移動了，Γ 和 SWR 也跟著變。

原因：圖上畫的是 z = Z_L/Z₀。分母換了，正規化的結果當然換了。例如 Z_L = 100 Ω：在 Z₀ = 50 的圖上是 z = 2（Γ = 1/3、SWR = 2）；在 Z₀ = 100 的圖上是 z = 1（Γ = 0、完美匹配）。

工程上的意義：「匹配」不是負載本身的性質，而是負載與那條線的關係。同一支天線接 50 Ω 同軸線可能很匹配，接 75 Ω 有線電視線就不匹配了。所以每張史密斯圖都必須先講清楚 Z₀ 是多少。

🤔 引導問題

推法一（代公式，最快）：λ/4 線的輸入阻抗是 Z_in = Z₁²/Z_L。要匹配就要 Z_in = Z₀，於是 Z₁²/Z_L = Z₀ → Z₁ = √(Z₀Z_L)。

推法二（物理，看得見）：現在有兩個界面各自會反射：

  • 前界面 Z₀→Z₁：Γ₁ = (Z₁−Z₀)/(Z₁+Z₀)
  • 後界面 Z₁→Z_L：Γ₂ = (Z_L−Z₁)/(Z_L+Z₁)

取 Z₁ = √(Z₀Z_L) 時，可以驗算出 |Γ₁| = |Γ₂|（畫面上兩格數字會一模一樣）。而第二個反射波必須在 λ/4 的線裡走一個來回，也就是多走 λ/2 → 多出 e−j2β(λ/4) = e−jπ = −1 的相位，剛好反相。

兩個大小相同、相位相反的反射波 → 完全相消。這就是 λ/4 的「4」的來源：只有走四分之一波長，來回才剛好是半個波長、才剛好翻 180°。

（嚴格說還有無窮多次來回反射，但把等比級數加總起來，結果仍然精確為零——這一點用公式法 Z_in = Z₁²/Z_L 一行就保證了。）

並聯的元件，導納直接相加：Y_total = Y_line + Y_stub。加法比阻抗並聯的 (1/Z₁+1/Z₂)⁻¹ 好算太多，所以整套流程改用導納 y = 1/z。

三個步驟：

  1. 從負載往電源走一段距離 d，走到正規化導納的實部剛好等於 1 的地方，也就是 y(d) = 1 + jb。（在史密斯圖上：沿等 SWR 圓順時針轉，直到碰到 g = 1 那個圓。這個圓一定會被碰到兩次 → 兩組解。）
  2. 剩下的 jb 是多餘的電納，用一段截線產生 −jb 把它抵掉。
  3. 短路截線的導納是 y = −j cot(βℓ_s)，解出長度 ℓ_s；開路截線則是 y = +j tan(βℓ_s)。

結果：接點左側 y = 1 + jb − jb = 1 → 完全匹配，往電源看過去 SWR = 1（右圖包絡在接點左邊變平）。但接點與負載之間那一段仍然有駐波，這一段本來就消不掉——請在右圖親眼確認這件事。

轉換器完全失效，|Γ_in| 回到「沒有轉換器」時的值。

原因：那段線的實體長度是固定的。頻率加倍 → 波長減半 → 同一段實體長度從 λ₀/4 變成 λ/2。而半波長線「阻抗原封不動」，所以看進去就是 Z_L 本人，轉換器等於不存在。

這正是「電長度 vs 實體長度」的最佳示範：電路認得的是 βℓ（電長度），不是幾公分。βℓ = (2π/λ)ℓ，其中 λ 隨頻率變。同一根線在不同頻率下是完全不同的元件。

動手試：慢慢把 f/f₀ 從 1.0 拉到 2.0，看左圖的紅點沿著碗形曲線爬上去，右圖的包絡從平的慢慢長回波浪。

⑤ 五個最常見的誤解（考前必看）

這五題對應傳輸線學習上最容易出錯的地方。每一條都配了「回去用哪個模式驗證」。

誤解 ①　「相速度 v_p 就是光速 c」

✗ 錯：訊號在同軸線裡也是以 3 × 10⁸ m/s 跑。

✓ 對：v_p = 1/√(LC) = 1/√(με) = c/√ε_r（無損耗線）。介質的相對介電常數 ε_r 一定大於 1，所以線上的速度永遠比光速慢。

  • 常見的 PE 絕緣同軸線 ε_r ≈ 2.25 → v_p ≈ 0.67c，也就是資料手冊上寫的 velocity factor 0.66。
  • 連帶的後果：λ = v_p/f 也比自由空間的波長短。1 GHz 在空氣中 λ = 30 cm，在該同軸線裡只有 20 cm。做 λ/4 截線時如果用 30 cm 去除以 4，長度會錯 1.5 倍，整個匹配網路報廢。
  • 只有空氣介質（或真空）的 TEM 線才等於 c。這一點值得特別注意。

🔁 回去驗證：模式④ 把 f/f₀ 拉一拉，體會「同一段實體長度、不同頻率＝不同電長度」。

誤解 ②　「史密斯圖上直接標 Z_L 的歐姆數就好」

✗ 錯：Z_L = 100 + j50 Ω，就在圖上找「100」和「50」。

✓ 對：史密斯圖只認正規化阻抗 z = Z/Z₀，圖上沒有歐姆這個單位。Z₀ = 50 Ω 時要標的是 z = 2 + j1。讀完答案再乘回 Z₀ 才是真正的歐姆值。

  • 口訣：進圖除以 Z₀，出圖乘以 Z₀。
  • 同一顆負載在不同 Z₀ 的圖上位置不同 → 「匹配」講的是負載與線的關係，不是負載自己的性質。
  • 導納也一樣要正規化：y = Y/Y₀ = Y·Z₀。

🔁 回去驗證：模式③ 固定 R_L = 100 Ω 不動，只拉 Z₀ 滑桿，看點在圖上跑來跑去。

誤解 ③　「電壓最大的地方，一定就在負載上」／「V_max 和 V_min 的位置隨便記」

✗ 錯：反正負載是「終點」，波打過去疊起來一定最大。

✓ 對：要看 Γ 的相角 θ_Γ：z′_max = θ_Γ λ/(4π)。

誤解 ④　「開路就是 Γ = −1、短路就是 Γ = +1」（邊界條件記反）

✗ 錯：「開路 = 沒有東西 = 負的」這種聯想。

✓ 對：用物理邊界條件推，不要背：

  • 短路（Z_L = 0）：兩導體被接在一起，電壓必須是 0。要讓 V⁺ + V⁻ = 0，只能 V⁻ = −V⁺ → Γ = −1。（電流反而加倍：I⁺ − I⁻ = 2I⁺。）
  • 開路（Z_L = ∞）：電路被切斷，電流必須是 0。要讓 I⁺ − I⁻ = 0，只能 I⁻ = I⁺，換算成電壓就是 V⁻ = +V⁺ → Γ = +1。（電壓反而加倍。）
  • 代公式檢查也行：Γ = (Z_L − Z₀)/(Z_L + Z₀)。Z_L = 0 → (−Z₀)/(Z₀) = −1 ✓；Z_L → ∞ 時分子分母都被 Z_L 主宰 → +1 ✓。

順帶提醒：電流反射係數 = −Γ（電壓反射係數的負值），特別注意「它不等於電壓反射係數」。

🔁 回去驗證：模式② 看短路那一列在 z′ = 0 是不是壓成 0；模式③ 按「短路」看點是不是跳到最左邊。

誤解 ⑤　「電長度就是實體長度」／「一根線就是一根線」

✗ 錯：10 公分的線，永遠是 10 公分的線。

✓ 對：電路看得到的是電長度 βℓ = (2π/λ)ℓ（單位是弧度或度），或等價的 ℓ/λ（幾個波長）。同一根線在不同頻率下是完全不同的元件。

  • 例：ε_r = 2.25 的線上，1 GHz 時 λ = 20 cm，所以 10 cm = λ/2（阻抗不變）；2 GHz 時 λ = 10 cm，同一根變成 1λ；500 MHz 時變成 λ/4（阻抗翻轉）。同一根銅線，三種完全不同的行為。
  • 反過來的判準：當 ℓ 遠小於 λ 時（大約 ℓ < λ/20），才可以忽略傳輸線效應當成普通導線。60 Hz 市電的 λ 有 5000 km，家裡的電線當然不用管；但 5 GHz 的 λ 只有 6 cm，PCB 上 1 公分的走線就已經是傳輸線了。
  • 相關公式（tan βℓ、e−jβz′、史密斯圖轉 2βd）裡出現的都是電長度，沒有一個是公分。

🔁 回去驗證：模式④ 把 f/f₀ 從 1.0 拉到 2.0，看 λ/4 轉換器怎麼在頻率加倍時變成半波長線而完全失效。
