區塊鏈概論

Introduction to Blockchain

什麼是區塊鏈？
What is Blockchain?
中文

區塊鏈（Blockchain）是一種分散式帳本技術。簡單來說，它就像一本所有人共同維護的帳本，沒有任何單一中心伺服器控制。每一筆交易紀錄都被打包成「區塊（Block）」，再用密碼學的方式將區塊一個接一個串聯起來，形成一條「鏈（Chain）」。

區塊鏈以複雜的密碼學來加密資料，並透過巧妙的數學分散式演算法，讓互聯網最令人擔憂的分散式系統安全信任問題，可以在不需要第三方介入的前提下讓使用者達成共識。

English

Blockchain is a distributed ledger technology. Think of it as a shared notebook maintained by everyone, with no single central server in control. Each transaction record is packed into a "Block," then linked together using cryptography to form a "Chain."

Blockchain uses complex cryptography to encrypt data, and through clever distributed algorithms, solves the trust problem in decentralized systems — allowing users to reach consensus without any third-party intermediary.

💡 生活比喻 Life Analogy

想像你和朋友們一起記帳。每個人手上都有一本完全相同的帳本。每次有人花錢或收錢，所有人同時更新自己的帳本。如果有人想偷改帳目，其他人馬上就會發現——因為大家的帳本不一致了。這就是區塊鏈的核心概念！

Imagine you and your friends all keep the same notebook. Every time someone spends or receives money, everyone updates their copy simultaneously. If anyone tries to cheat, others will notice immediately because the records won't match. That's blockchain!

中文詳解

➊ 使用者由錢包（Wallet）產生一筆新交易。

➋ 交易被廣播到區塊鏈網絡中的所有參與節點。

➌ 每個節點會將數筆未驗證的交易（Unconfirmed Transaction）收集到區塊中，每個區塊可以包含數百筆至上千筆交易。

➍ 各節點進行工作量證明（Proof of Work, PoW）的計算來決定誰可以驗證交易，最快算出結果的節點取得記帳權——這就是挖礦。

➎ 最快完成 PoW 的節點，會將自己的區塊廣播給其他所有節點。其他節點確認交易是否有效、未被重複花費。

➏ 驗證通過後，此區塊正式接上區塊鏈，無法再被篡改。所有節點重新開始下一回合的 PoW 計算。

English Explanation

➊ A user creates a new transaction from their wallet.

➋ The transaction is broadcast to all participating nodes in the blockchain network.

➌ Each node collects multiple unconfirmed transactions into a block. Each block can contain hundreds to thousands of transactions.

➍ Nodes perform Proof of Work (PoW) calculations to determine who verifies the transactions. The fastest node earns the right to record — this is called mining.

➎ The winning node broadcasts its block to all other nodes for verification — confirming transactions are valid and not double-spent.

➏ Once verified, the block is permanently appended to the blockchain. All nodes begin the next round of PoW computation.

交易（Transaction）vs 區塊（Block）
Transactions vs Blocks
中文

比特幣區塊鏈運作，是由多個區塊鏈結在一起而成。每一個區塊包含了許多交易（Transaction）紀錄。

礦工挖礦，其實就是在競逐記帳權，而挖到礦，則有固定數額的比特幣獎勵。

一個區塊包含：區塊頭（Block Header）= 前一個區塊的 Hash + Merkle Root + 時間戳 + 難度值 + Nonce 值，以及區塊體= 本區塊的所有交易紀錄。

English

The Bitcoin blockchain operates by linking multiple blocks together. Each block contains many transaction records.

Mining is actually a competition for the right to record transactions, and the reward is a fixed amount of Bitcoin.

A block contains: Block Header = Previous Block Hash + Merkle Root + Timestamp + Difficulty + Nonce, and Block Body = All transaction records in this block.

比特幣交易與密碼學 Bitcoin Transactions & Cryptography
Public Key, Private Key, and Wallet Address
中文

交易流程：比特幣交易從位址 A 傳送到位址 B 時，交易資料經由數位簽章加密，傳送者（sender）須經由私鑰證明擁有比特幣。收受方提供公鑰（轉換成位址形式，公開、可追蹤）。

密碼學流程：

➊ 隨機產生一把私鑰（2256 種可能）

➋ 透過橢圓曲線演算法（SECP256K1）產生對應公鑰

➌ 公鑰經 SHA-256 + RIPEMD-160 雜湊得到公鑰雜湊

➍ 再經 Base58Check 編碼得到錢包地址

重點：私鑰 → 公鑰 → 地址，這個過程是單向不可逆的！

English

Transaction flow: When sending Bitcoin from Address A to B, the data is encrypted via digital signature. The sender proves ownership using their private key. The receiver provides their public key (converted to an address format, publicly trackable).

Cryptography flow:

➊ Randomly generate a private key (2256 possibilities)

➋ Use elliptic curve algorithm (SECP256K1) to derive the public key

➌ Hash the public key with SHA-256 + RIPEMD-160 to get public key hash

➍ Encode with Base58Check to get the wallet address

Key point: Private Key → Public Key → Address is a one-way, irreversible process!

🔑
關鍵比喻 Key Analogy：
私鑰 = 你的密碼（絕對不能給別人）Private Key = Your password (never share!)
公鑰 = 你的銀行帳號（可以給人轉帳）Public Key = Your bank account number (safe to share)
錢包地址 = 你的收款二維碼 Wallet Address = Your payment QR code

Hash 與挖礦

Hash Functions & Mining

何謂 Hash（雜湊／哈希）？
What is a Hash Function?
中文

Hash（雜湊函數）是一種數學函數，具有以下三大特性：

✅ 固定長度輸出：不管輸入多長多短，都產生相同長度的輸出（例如 SHA-256 永遠輸出 64 個十六進位字元）

✅ 抗碰撞性：無法找到「不同輸入」來源，得到相同輸出

✅ 單向性：無法反推輸出的字串回去輸入（不可逆）

English

A Hash function is a mathematical function with three key properties:

✅ Fixed-length output: Regardless of input length, the output is always the same length (e.g., SHA-256 always outputs 64 hexadecimal characters)

✅ Collision-resistant: It's nearly impossible to find two different inputs that produce the same output

✅ One-way: You cannot reverse-engineer the input from the output

比特幣分叉幣知識 Bitcoin Forks
Understanding Bitcoin Forks
中文

自從 Bitcoin Cash（BCH）在2017年誕生以來，比特幣分叉幣數量已超過 74 個。分叉（Fork）是指區塊鏈網絡的協議規則發生變更，導致產生新的分支鏈。

知名的分叉幣包括：Bitcoin Cash (BCH)、Bitcoin SV (BSV)、Bitcoin Gold (BTG) 等。許多分叉幣最終沒有獲得足夠的社群支持而逐漸消失。

English

Since Bitcoin Cash (BCH) was born in 2017, there have been over 74 Bitcoin forks. A fork occurs when a blockchain's protocol rules change, creating a new branch chain.

Notable forks include: Bitcoin Cash (BCH), Bitcoin SV (BSV), Bitcoin Gold (BTG), etc. Many forks eventually fade without sufficient community support.

The World Computer

以太坊簡介
Introduction to Ethereum
中文

以太坊（Ethereum）是一個開源、有「智能合約」功能的公共區塊鏈平台。通過其專用加密貨幣以太幣（Ether, ETH），提供去中心化的虛擬機器（稱為「以太虛擬機」Ethereum Virtual Machine, EVM）來處理對等合約。

以太坊的概念首次在 2013 至 2014 年間由程式設計師 Vitalik Buterin（維塔利克·布特林）受比特幣啟發後提出。他當時年僅 19 歲！大意為「下一代加密貨幣與去中心化應用平台」，在 2014 年透過 ICO 眾籌得以開始發展。

簡單說，以太坊 = 打造區塊鏈應用的工廠。它最主要的價值就是提供 DApp（Decentralized App, 去中心化應用程式）開發者必要的材料、工具和基礎設施，降低 DApp 的開發門檻。

English

Ethereum is an open-source public blockchain platform with "smart contract" functionality. Through its cryptocurrency Ether (ETH), it provides a decentralized virtual machine (EVM) to process contracts.

Ethereum was first proposed in 2013–2014 by programmer Vitalik Buterin, inspired by Bitcoin. He was only 19! It was described as "the next-generation cryptocurrency and decentralized application platform," and was funded through an ICO in 2014.

Simply put, Ethereum = a factory for building blockchain applications. Its primary value is providing DApp developers with essential materials, tools, and infrastructure.

智能合約 Smart Contracts

Code is Law

什麼是智能合約？
What is a Smart Contract?
中文

智能合約（Smart Contract）是一段寫在區塊鏈上、可自動執行的程式碼。當預設的條件被滿足時，合約會自動執行對應的操作，不需要任何中介機構。

由於智能合約可在每個以太坊的節點上執行並進行驗證，所以計算結果被認為是可信任的。以太坊還開發出了 Web3.js 讓開發者可以使用網頁技術撰寫智能合約的操作介面，這樣的網頁操作介面又稱為 DApp（分散式應用程式）。

English

A Smart Contract is self-executing code written on the blockchain. When preset conditions are met, the contract automatically executes the corresponding operations without any intermediary.

Since smart contracts run and are verified on every Ethereum node, their results are trusted. Ethereum also created Web3.js for building web-based interfaces for smart contracts — these are called DApps (Decentralized Applications).

💡 生活比喻 Life Analogy

智能合約就像自動販賣機：你投入硬幣（滿足條件），機器就自動給你飲料（執行合約）。整個過程不需要店員（中介機構），而且規則透明、不可更改。

A smart contract is like a vending machine: insert coins (meet conditions), and the machine automatically gives you a drink (executes contract). No shopkeeper (intermediary) needed, and the rules are transparent and unchangeable.

智能合約開發工具 Development Tools
Smart Contract Tech Stack
📝 Solidity — 智能合約程式語言 ▼

Solidity 是以太坊智能合約的主要程式語言，語法類似 JavaScript。開發者用 Solidity 編寫合約邏輯，編譯成 Bytecode 後部署到以太坊網路。

Solidity is the main programming language for Ethereum smart contracts. Its syntax is similar to JavaScript. Developers write contract logic in Solidity, compile it to bytecode, then deploy to the Ethereum network.

🛠️ Remix IDE — 線上開發環境 ▼

Remix 是一個免費的線上 IDE（remix.ethereum.org），可以直接在瀏覽器中編寫、編譯、部署和測試 Solidity 智能合約，非常適合初學者。

Remix is a free online IDE where you can write, compile, deploy, and test Solidity smart contracts directly in your browser — perfect for beginners.

🦊 MetaMask — 以太幣錢包 ▼

MetaMask 是最熱門的以太坊瀏覽器錢包。可以用來產生網址或接收、發送交易，也可以直接與瀏覽器 DApp 進行連結並執行相關的交易。它讓使用者可以很容易跟以太坊的智能合約互動。

MetaMask is the most popular Ethereum browser wallet. It generates addresses, receives/sends transactions, and connects directly to browser DApps. It makes interacting with smart contracts easy.

🔧 Truffle & Web3.js — 開發框架 ▼

Truffle 是基於 Node.js 的以太坊開發框架，提供合約編譯、部署、測試的完整工具鏈。Web3.js 則是連接前端網頁與以太坊區塊鏈的 JavaScript 函式庫。

Truffle is a Node.js-based Ethereum development framework providing compilation, deployment, and testing tools. Web3.js is the JavaScript library connecting front-end web pages to the Ethereum blockchain.

Q1. 區塊鏈的核心特性「不可篡改」主要依靠什麼技術實現？

What technology primarily enables blockchain's "immutability"?

A. 人工智慧 Artificial Intelligence
B. 密碼學雜湊函數 Cryptographic Hash Functions
C. 雲端運算 Cloud Computing
D. 5G 通訊技術 5G Communication
✅ 正確！區塊鏈用 Hash 函數串聯區塊，改一個字元整個 Hash 都會變——這就是防篡改的關鍵。
Correct! Hash functions link blocks together. Changing one character changes the entire hash — the key to tamper-proofing.

Q2.「挖礦」在比特幣區塊鏈中是指什麼？

What does "mining" mean in the Bitcoin blockchain?

A. 在地下挖掘實體比特幣 Digging physical bitcoins underground
B. 下載比特幣軟體 Downloading Bitcoin software
C. 透過計算找到符合難度的 Nonce 值以取得記帳權 Finding a valid Nonce through computation to earn recording rights
D. 購買加密貨幣 Buying cryptocurrency
✅ 正確！挖礦就是不斷嘗試 Nonce 值，找到使 Hash 開頭有足夠多零的那個值。
Mining means trying Nonce values repeatedly to find one that produces a hash with enough leading zeros.

Correct! Ethereum introduced smart contracts — self-executing code on blockchain, ushering in Blockchain 2.0.

Q4. 下列哪一項不是 Hash 函數的特性？

Which of the following is NOT a property of hash functions?

A. 固定長度輸出 Fixed-length output
B. 可以從輸出反推輸入 Can reverse output to input
C. 抗碰撞性 Collision-resistant
D. 雪崩效應 Avalanche effect
✅ 正確！Hash 函數是單向不可逆的，無法從輸出反推回輸入。
Correct! Hash functions are one-way — you CANNOT reverse the output to find the input.
