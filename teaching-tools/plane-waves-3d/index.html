🎯 該注意哪裡：
  • 三個方向永遠互相垂直：E ⊥ H、E ⊥ ẑ、H ⊥ ẑ。這就是「橫向電磁波（TEM wave）」的意思——E 和 H 都躺在垂直於傳播方向的橫截面上。
  • E 和 H 同時到最大、同時歸零（無損耗介質中兩者同相）。所以綠色的 S 箭頭時長時短，但方向永遠是 +z，不會倒退。
  • 把 f 調高 → 畫面上的波「變密」，因為 λ = vₚ/f 變短，但 vₚ 不變（vₚ 只跟介質有關）。
  • 把 εᵣ 調大 → vₚ 和 λ 一起變小、η 也變小 —— 波在介質裡「跑得比較慢、縮得比較短」。
本模式使用的式子
E(z,t) = x̂ E₀ cos(ωt − kz)　　H(z,t) = ŷ (E₀/η) cos(ωt − kz)
k = ω√(με) = 2π/λ　　vₚ = ω/k = 1/√(με)　　η = √(μ/ε)　　S = E × H
⚠️ 畫面上的注意事項：圖裡 H 的箭頭長度已經放大過。真實情況 H₀ = E₀/η，在自由空間 η ≈ 377 Ω，所以 H 的數值只有 E 的 1/377——照實畫你會完全看不到藍色。

🤔 引導問題（先自己想，再展開）

變密。視窗長度固定，f 加倍 → λ = vₚ/f 減半 → 同一段距離裡塞進兩倍的週期數。

vₚ 完全不變。vₚ = 1/√(με) 只跟介質有關，跟頻率無關（在非色散的無損耗介質中）。這點是初學最常錯的地方：「頻率高 → 跑得快」是錯的，頻率高只是「波長短」。

是，兩者同相（相位差 0°）。因為在無損耗介質中 η = √(μ/ε) 是實數，H = E/η 沒有額外的相位移。

把視角轉到「正側視」和「正上視」交替看，會發現紅藍兩條曲線的波峰在同一個 z 位置上。（等一下到模式③ 有耗介質，η 會變成複數，H 就會落後 E —— 那時候再回來對照這一題。）

S = E × H = ẑ E₀H₀cos²(ωt − kz)。cos² 永遠 ≥ 0，所以方向恆為 +z，只有大小在起伏。

而且 cos² 的振盪頻率是原本的兩倍（一個週期內 S 會鼓兩次），這也是為什麼時間平均值是 S_av = E₀²/(2η) 而不是 E₀²/η。

物理意義：能量一路往前送、不會倒流。等到模式④ 有反射波時，往回的那一支才會出現。

② 平面波的極化 Polarization

👀 你現在在看什麼：把電場拆成兩個互相垂直的分量—— Eₓ（x 方向）和 E_y（y 方向），它們各自都只是普通的線性振盪。 紫色是兩者的合成向量。 右圖是站在 z = 0 的橫截面上，看合成向量的末端畫出什麼軌跡。
💡 生活類比：一個人在畫圈圈
你左右擺手（Eₓ）、同時上下點頭（E_y）。如果擺手到最右邊時剛好頭在正中間（相差 90°），別人從正前方看，你的鼻尖就在畫圓。 圓極化不是「波在轉」，而是兩個原地振盪的分量合出來的結果。

🎯 該注意哪裡：
  • 拉 δ 滑桿從 0° 慢慢到 −90°（保持 E₁ = E₂）：軌跡從一條斜直線 → 越來越胖的橢圓 → 正圓。三種極化其實是同一個式子的三種情形，不是三種不同的波。
  • 線性極化：方向固定、大小在變。圓極化：大小固定、方向在轉。這兩句話請背起來。
  • 把 E₂ 調成 0：只剩 Eₓ，變回模式① 那個 x 極化的波。模式① 是本模式的特例。
  • 看左圖的紫色螺旋：圓極化在空間中是一條螺旋線（helix），這是「快照」不是「在轉的東西」。
本模式使用的式子（合成兩個正交線性極化波）
E(z,t) = x̂ E₁cos(ωt − kz) + ŷ E₂cos(ωt − kz + δ)
δ = 0 或 ±180° → 線性極化　｜　E₁ = E₂ 且 δ = ±90° → 圓形極化　｜　其餘 → 橢圓極化
⚠️ 旋向慣例（最容易被考倒的地方）
本模擬採 IEEE 右手定則慣例：右手大拇指指向傳播方向 +z，四指彎曲方向 = E 的旋轉方向 → 稱為右旋（right-hand）。
右圖是「+z 朝向你」的視角，所以右旋在畫面上看起來是逆時針。 如果換成「順著傳播方向看（+z 離你而去）」，畫面上的旋轉方向會左右顛倒——看到不同教科書講法不一樣時，先確認對方是站在哪一邊看。 （另外，光學領域還有一套相反的慣例，使用時請先確認慣例。）
💡 補充：AM 廣播 = 線性極化且 E 垂直於地面；電視訊號 = 水平方向的線性極化；FM 廣播 = 一般為圓形極化。GPS 衛星也用圓極化——因為訊號穿過電離層時極化方向會被轉動，用圓極化就不怕收不到。

🤔 引導問題

δ = 0° → 45° 的斜直線（線性極化）。δ 往負向走（|δ| 變大） → 直線「撐開」成橢圓極化，越來越胖。δ = −90° → 剛好變成正圓（圓形極化）。

往正向調（δ = +90°）也會變成正圓，只是旋向相反（左旋）。決定胖瘦的是 |δ|，決定旋向的是 δ 的正負號。

對應的軸比 AR：從 ∞（線性）連續變到 1（圓）。橢圓極化是最一般的情形，線性和圓形都只是它的特例。

不會。|E| = √(E₁²cos²ωt + E₂²sin²ωt)，當 E₁ = E₂ = E₀ 時就是 √(E₀²) = E₀ 恆定，只有方向在轉。（看「|E| 是否隨時間變」那格顯示「否（恆定）」）

線性極化剛好相反：方向固定、大小從 +E₀ 振盪到 −E₀，中間會經過 0。

關鍵在相位差。以 δ = −90°、E₁ = E₂ = E₀ 為例，看合成向量在一個週期內的四個時刻：

ωtEₓE_y合成向量指向
0°E₀0+x（右）
90°0E₀+y（上）
180°−E₀0−x（左）
270°0−E₀−y（下）

一個到最大時另一個剛好是零，接力下去，末端就依序走過 右→上→左→下，畫出一個圓。沒有任何東西在旋轉，是「兩個原地振盪的合成」在轉。

③ 有耗介質中的衰減與集膚深度 skin depth δ

👀 你現在在看什麼：同樣是往 +z 前進的平面波，但介質會導電（σ ≠ 0），能量被消耗掉，所以振幅隨 z 指數衰減。 灰色虛線是包絡 ±E₀e−αz， 橘色標記是集膚深度 skin depth δ（振幅剩下 e⁻¹ ≈ 36.8% 的位置）。

🤔 引導問題

變小。良導體中 δ = 1/√(πfμσ)，σ 在分母的根號裡，σ 越大 δ 越小（σ 變 100 倍，δ 變 1/10）。

物理上：導電率越高，波一進入介質就感應出越強的表面電流，這些電流產生的場把入射場抵銷掉，所以波「進不去」，全部擠在薄薄的表層。極限情形是理想導體 σ → ∞ ⇒ δ → 0，波完全進不去、全部被反射（模式④ 會看到）。

變成 10 倍。δ ∝ 1/√f，f 降 100 倍 → √f 降 10 倍 → δ 升 10 倍。

你可以在畫面上直接讀數字驗證：銅在 1 GHz 約 2.1 µm，在 10 MHz 約 21 µm。（這是「高頻用不到導線內部、乾脆做成空心管」的原因。）

不同相。因為 η = √(jωμ/(σ+jωε)) 變成複數，其相角 θ_η 在良導體時 → 45°，也就是 H 落後 E 45°。

畫面判斷法：切到「正側視」，比較紅色 E 的波峰和藍色 H 的波峰。理想介電質時兩者對齊；銅導體時藍色波峰明顯落在紅色波峰的後方（−z 那一側），差距約 λ/8（45° = 360°/8）。

後果：E 和 H 不同相 → 玻因亭向量的時間平均值 S_av = ½Re{E × H*} 變小，能量大部分變成熱（歐姆損耗）而不是往前傳。

④ 平坦介電質界面上的反射與透射

👀 你現在在看什麼：這是入射平面（plane of incidence）的剖面圖——由入射方向與界面法線決定的那個平面。 左半邊是介質 1（εᵣ₁），右半邊是介質 2（εᵣ₂），中間那條粗線是界面。 背景顏色是總場的瞬時值（紅 = 正／藍 = 負）， 上面畫了入射／反射／透射三支波的方向箭頭，下方細長條是切向場的包絡（駐波圖樣）——⊥ 極化畫 |E_y|、∥ 極化畫 |H_y|，標籤會跟著切換。

🎯 該注意哪裡：
  • θᵢ = 0（正入射）：三支波疊在同一條線上，Γ = (η₂−η₁)/(η₂+η₁)。左邊出現最清楚的橫條紋駐波。
  • 玻璃 → 空氣、θᵢ 過臨界角：透射的箭頭消失了，右半邊只剩貼著界面指數衰減的一層——那是消散波（evanescent wave），不帶走實功率，|Γ| = 1。
  • 選 ∥ 平行極化、把 θᵢ 慢慢移到布如斯特角：反射箭頭與左邊的條紋整個消失，Γ = 0。改選 ⊥ 垂直極化，同一個角度卻仍有反射——這就是偏光太陽眼鏡能擋路面反光的原理。
  • 看左邊的包絡曲線：|Γ| 越大條紋對比越強。SWR = (1+|Γ|)/(1−|Γ|)，Γ = 0 時包絡是一條平的直線（完全沒有駐波）。
本模式使用的式子
斯乃耳反射定律：θᵣ = θᵢ　｜　斯乃耳折射定律：n₁sinθᵢ = n₂sinθₜ　（n = √εᵣ，非磁性介質）
夫瑞奈方程式 Fresnel's equations：
⊥ 垂直極化：Γ⊥ = (η₂cosθᵢ − η₁cosθₜ)/(η₂cosθᵢ + η₁cosθₜ)，τ⊥ = 2η₂cosθᵢ/(η₂cosθᵢ + η₁cosθₜ)
∥ 平行極化：Γ∥ = (η₂cosθₜ − η₁cosθᵢ)/(η₂cosθₜ + η₁cosθᵢ)，τ∥ = 2η₂cosθᵢ/(η₂cosθₜ + η₁cosθᵢ)
邊界關係：⊥ 極化 1 + Γ⊥ = τ⊥（切向 E 連續）；∥ 極化 (1 − Γ∥)/η₁ = τ∥/η₂（切向 H 連續）。你可以拿畫面上的 Γ、τ 讀數代進去驗證。
臨界角 θ_c = sin⁻¹(n₂/n₁)（需 n₂ < n₁）　｜　布如斯特角 θ_B∥ = tan⁻¹(n₂/n₁)　｜　SWR = (1+|Γ|)/(1−|Γ|)
⚠️ 重點：在兩非磁性介質（μ₁ = μ₂ = μ₀）的界面上，只有平行極化 ∥ 存在布如斯特角；垂直極化 ⊥ 不存在布如斯特角。這也是它又叫「極化角 polarizing angle」的原因——非極化光以此角入射，反射出去的只剩垂直極化的分量。

🤔 引導問題

當 θᵢ 超過臨界角 θ_c = sin⁻¹(n₂/n₁)（玻璃 n₁ = 1.5 → 空氣 n₂ = 1，θ_c ≈ 41.8°）就發生全反射（total reflection）。

能量沒有進入介質 2。|Γ| = 1，入射功率全部被反射回介質 1。右半邊看到的那層貼著界面的場叫消散波（evanescent wave）：它沿 z 指數衰減、只沿界面（x 方向）跑，時間平均的功率流穿不過界面。

應用：光纖就是靠這招把光鎖在纖芯裡跑幾十公里。

數學上：Γ∥ = 0 需要 η₂cosθₜ = η₁cosθᵢ，配上斯乃耳定律解出 θ_B∥ = tan⁻¹(n₂/n₁)。空氣→玻璃（n₂/n₁ = 1.5）時 θ_B ≈ 56.31°。

物理上：在布如斯特角，反射方向恰好與透射波中電偶極的振盪方向平行。偶極沿著自己的軸線不輻射，所以那個方向沒有反射波。

為什麼 ⊥ 沒有：令 Γ⊥ = 0 需要 η₂cosθᵢ = η₁cosθₜ，配上斯乃耳定律平方相加後會推出 n₁ = n₂——也就是「兩邊本來就同一種介質」，那根本不是界面。所以非磁性介質中 ⊥ 極化不存在布如斯特角。

那是入射波與反射波疊加成的駐波（standing wave）。兩支波沿法線方向反向跑，某些位置永遠同相（最大 = (1+|Γ|)E₀），某些位置永遠反相（最小 = (1−|Γ|)E₀）。

對比的量化指標就是駐波比 SWR = E_max/E_min = (1+|Γ|)/(1−|Γ|)。

  • |Γ| = 0（阻抗匹配 / 布如斯特角）→ SWR = 1 → 包絡是平的，沒有條紋。
  • |Γ| = 1（全反射 / 打到理想導體）→ SWR = ∞ → 條紋最強，最小值降到 0（駐波節點）。

相鄰兩個最小值的距離要沿著法線（z 方向）量：

  • 正入射（θᵢ = 0）：λ₁/2，不是 λ₁——因為駐波看的是振幅（絕對值），一個週期裡過零兩次。
  • 斜入射：λ₁/(2cosθᵢ)。只有波向量的法線分量 k₁cosθᵢ 參與駐波，切向分量 k₁sinθᵢ 入射與反射兩支完全相同、抵銷不掉。θᵢ 越大，條紋被拉得越開。

本模擬預設 θᵢ = 30°，λ₁/(2cos30°) = 0.577λ₁，比正入射的 0.5λ₁ 寬了約 15%——你可以把 θᵢ 拉到 0° 再拉到 60°，直接看包絡條紋被拉開。
