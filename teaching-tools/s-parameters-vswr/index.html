量皆有定義

S 參數先看輸入與輸出波

[b₁ b₂]ᵀ = S[a₁ a₂]ᵀS₁₁ = b₁/a₁（a₂ = 0）

S₁₁、S₂₂是反射；S₂₁、S₁₂是兩個方向的傳輸。S 參數本身是複數比值。

教學用串聯 RLC 阻抗

Z(f) = R + jX(f)，X(f) = QR(f/f₀ − f₀/f) [Ω]

在 f = f₀ 時 X = 0；此時「共振」成立，但 R 還要等於 Z₀ 才同時匹配。

反射、dB 與回波損耗（Return Loss, RL）

Γ = (Z − Z₀)/(Z + Z₀)，|S₁₁| = |Γ||S₁₁|dB = 20 log₁₀|S₁₁|，RL = −20 log₁₀|Γ| [dB]

|S₁₁|dB 是負值或零；RL 用正值表達同一個反射幅度。例：S₁₁ = −20 dB 對應 RL = 20 dB。

VSWR、反射功率與頻寬

VSWR = (1 + |Γ|)/(1 − |Γ|)Prefl/Pinc = |Γ|²，ηm = 1 − |Γ|²BW−10 dB = fH − fL [Hz]

|Γ|² 是反射功率比例；其餘功率為此簡化模型中未反射而送入負載的功率。

常見迷思：三個最容易混淆的地方

先辨認再計算

迷思 1：−20 dB 比 −10 dB 更差

對 S₁₁ 而言，−20 dB 的反射幅度較小，匹配通常更好；要注意這是在看反射量。

迷思 2：共振一定等於理想匹配

共振只表示輸入電抗過零。若 R 與 Z₀ 不相等，S₁₁ 仍可能很高。

迷思 3：S₁₁ = −10 dB 代表反射功率 10 dB

−10 dB 對應 |Γ|≈0.316；反射功率比例 |Γ|² = 0.10，也就是 10%。
