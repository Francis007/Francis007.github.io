  • B(t) 過零的瞬間，感應電流最大；B(t) 在正／負峰值的瞬間，感應電流反而是零。因為 EMF ∝ dB/dt，而不是 ∝ B 本身——這是初學最容易搞混的地方。

🤔 引導問題（先自己想，再展開）

加倍。EMF_peak = N·A·B₀·ω，ω = 2πf 跟 EMF 振幅成正比，f 加倍 → ω 加倍 → EMF 振幅剛好加倍（B₀、N、A 都沒變）。

這跟 Ch08 「波速 vₚ 跟頻率無關」的結論不衝突——那裡討論的是波在空間中傳播的速度，這裡討論的是感應電動勢的大小，是兩件不同的事，只是剛好都跟頻率有關，一個是「無關」一個是「正比」，很容易混淆。

此時電流最大。B(t) 過零時斜率最陡（|dB/dt| 最大），而 EMF ∝ dB/dt，所以 EMF、電流都在此刻達到最大值——跟 B 本身的大小完全脫鉤。

方向判斷：B 正要從 0 往正方向增加，代表磁通正在增加，楞次定律要求感應電流的磁場指向反方向（抵消增加），用右手定則反推：拇指指向「抵消方向」，四指彎曲的方向就是電流方向。畫面上可以直接看綠色箭頭在這個瞬間翻轉。

N 加倍 → EMF 加倍（線性關係：N 匝等於把 N 個單匝線圈的 EMF 疊加起來）。

N 加倍且 A 也加倍 → EMF 變成 4 倍。EMF_peak = N·A·B₀·ω，N 和 A 各自貢獻一個因子 2，相乘是 4。用本模擬的「標準」預設（N=3）切到 N=6、半徑加大到面積兩倍，讀出來的 EMF 振幅應該是原本的 4 倍——可以自己拉滑桿驗證。

⚠️ 常見誤解：位移電流不是「真的電流」——極板之間是真空或介電質，沒有電荷在流動，J（傳導電流密度）確確實實是 0。∂D/∂t 只是在數學上、在安培定律裡扮演跟 J 一樣的角色，讓 ∇×H = J + ∂D/∂t 這條方程式對任何封閉曲面都成立（包括穿過電容器極板之間、完全沒有導線的曲面）。圖中 B 箭頭長度已放大以利觀察，真實數值請看右側讀數。

🤔 引導問題

沒有。兩片金屬板中間通常是真空或介電質，沒有自由電荷可以穿過，傳導電流密度 J 精確等於 0。

但電場 E（進而 D = ε₀εᵣE）隨著電源電壓 V(t) 在變化，∂D/∂t ≠ 0。Maxwell 把 ∂D/∂t 這一項加進安培定律：∇×H = J + ∂D/∂t。即使 J = 0，只要 ∂D/∂t ≠ 0，右邊還是不為零，左邊的 ∇×H 也就不為零——磁場因此存在。

兩者永遠相等：I_c(t) = I_d(t) = C·dV/dt，其中 C = ε₀εᵣπR²/d 是電容器的電容。

這不是巧合，而是電荷守恆的必然結果：導線把電荷送到極板上（I_c = dQ/dt），極板上累積的電荷 Q = CV 決定了極板間的 D 場（D = Q/(πR²)），兩者用同一個 Q(t) 串起來，微分之後自然相等。物理意義：把「傳導電流＋位移電流」加在一起看，電流在整個電路（含電容器這個斷點）裡是連續的，不會憑空消失。

用安培-馬克斯威爾定律取一個半徑 r 的圓形迴路：∮H·dl = H(r)·2πr = 被這個迴路圍住的位移電流 I_enc(r)。

r ≤ R（迴路在極板內部）：位移電流密度 J_d 均勻分布，被圍住的電流正比於面積 πr²，所以 I_enc(r) = J_d·πr² ∝ r²，代入後 H(r) = J_d·r/2 ∝ r——線性增加，就像螺線管內部的磁場算法。

r > R（迴路已經圍住整片極板）：不管 r 再怎麼加大，圍住的位移電流都固定是 I_d（總量不會再增加），所以 H(r) = I_d/(2πr) ∝ 1/r——行為就跟一根載流 I_d 的無限長直導線一模一樣。這也是為什麼在很遠的地方，一個變化的電容器看起來就像一根通有電流 I_d 的導線。

🎯 該注意哪裡：
  • 切到「只看 Faraday」：畫面提示你注意藍色 B 隨時間變化（∂B/∂t）如何要求旁邊出現一個環繞的 E（∇×E）——這一條方程式單獨看，只能告訴你「有 ∂B/∂t 就會有 ∇×E」，還沒告訴你 E 怎麼變化。
  • 切到「只看 Ampère-Maxwell」：換成注意紅色 E 隨時間變化（∂D/∂t）如何要求旁邊出現一個環繞的 H（∇×H）。
  • 兩條方程式必須同時成立、互相牽制，才能解出「E 和 B 都以相同的 ω、k 一起振盪、一起向前跑」這個平面波解——單獨拿掉任何一條，波動方程式都推不出來。這就是「耦合」的意思：不是先有 E 才有 B，也不是先有 B 才有 E，是兩者同時被兩條方程式綁定。
  • 三個方向永遠互相垂直（E ⊥ B ⊥ k），這是「橫向電磁波 TEM」的意思，跟 Ch08 討論的是同一件事，只是這裡的重點放在「為什麼會這樣耦合出來」。

平面波解：E(z,t) = x̂E₀cos(ωt−kz)　　B(z,t) = ŷ(E₀/vₚ)cos(ωt−kz)　　vₚ = 1/√(με)　　k = ω√(με)
⚠️ 常見誤解：「E 生 B，B 又生 E」聽起來像接力賽（先有 E，才生出 B，再生回 E……），但這不是因果關係，而是耦合關係——在空間中每一點、每一個時刻，E 和 B 同時存在、同時變化，兩條方程式同時對它們施加限制，解出來的結果剛好是「兩者綁在一起、以波的形式共同前進」。沒有誰先誰後，就像一對互相牽制的齒輪同時轉動，不是其中一個先轉動另一個才跟著轉。

🤔 引導問題

不能。在馬克斯威爾把 ∂D/∂t 補進安培定律之前，安培定律只有 ∇×H = J（傳導電流）。在真空、無源的空間裡 J = 0，那條方程式會直接告訴你 ∇×H = 0——磁場沒有旋度，變化的 E 場完全沒辦法產生新的 H 場。

少了這個回饋機制，Faraday 定律（∇×E = −∂B/∂t）雖然還能讓變化的 B 產生 E，但這個 E 沒有機制再產生新的 B，整個「自我維持」的鏈就斷了，波動方程式 ∇²E = με∂²E/∂t² 也推不出來。這正是馬克斯威爾當年加上位移電流項的關鍵動機：唯有兩條方程式同時耦合，電磁波才能不靠任何導線、不靠任何介質中的電荷，單靠場本身在真空中自我維持地傳播下去。

誰都沒有先引起誰——這是耦合（coupled），不是因果（causal）鏈。在穩定傳播的平面波裡，E(z,t) 和 B(z,t) 用同一組 (ω,k) 同時振盪、同時存在，兩條旋度方程式在空間中每一點都同時成立，缺一不可。

把「E 生 B、B 又生 E」想成接力賽是最常見的誤解。比較貼切的比喻是：兩條方程式像兩個互相咬合的齒輪，同時轉動，彼此的轉動速度互相牽制——不會有「先動的那一個」。

vₚ 變小（vₚ = 1/√(μ₀εᵣε₀) ∝ 1/√εᵣ），在頻率 f 不變的前提下 λ = vₚ/f 也跟著變小。拉高 εᵣ 滑桿，畫面上的波形會明顯「縮短、變密」。

是同一件事。Ch08 強調的是 vₚ 這個量本身只由介質的 μ、ε 決定，跟頻率無關；這裡則是從「兩條方程式耦合解出波動方程式」的角度，說明 vₚ 這個常數從何而來——它就是波動方程式 ∇²E = με∂²E/∂t² 裡，係數 με 開根號取倒數的結果。兩章講的是同一個 vₚ，只是切入角度不同。

④ 螺線管的感應 E 場：∇×E = −∂B/∂t 的旋度視覺化

💡 延伸應用——這裡用的仍是同一條法拉第定律（∮E·dl = −dΦ/dt），只是換一個更直觀的幾何形狀來看「變化的 B 感應出環繞的 E」。
👀 你現在在看什麼：一個長螺線管，內部有均勻但隨時間變化的磁場 B(t) （藍色，只存在於半徑 R 以內）。 這個變化的 B 會在整個空間（不管裡面還是外面，甚至完全沒有導線的地方）感應出環繞的電場 E （綠色箭頭）——這是 ∇×E = −∂B/∂t 最直接的畫面。
💡 跟模式① 對照著看：模式① 是「外部變化的 B 穿過一個固定的線圈，逼出感應電流」——你看到的是電流，而且只在線圈那一圈才看得到。 這裡反過來：B 的變化本身在空間中處處感應出一圈一圈的 E，不需要任何導線——把一段導線放進任何一圈，量到的 EMF 就是那一圈的 E 場繞一周的線積分。E 場本身才是「因」，導線只是拿來量測它的工具。

r ≤ R：Φ_enc = B(t)·πr²　⇒　E(r) = −(r/2)·dB/dt
r > R：Φ_enc = B(t)·πR²　⇒　E(r) = −(R²/2r)·dB/dt
💡 為什麼要在乎這個？這正是電子迴旋加速器（betatron）的工作原理：讓帶電粒子繞著螺線管外的圓形軌道跑，磁場變化在軌道上感應出的 E 場持續加速粒子——完全不需要任何電極或導線直接接觸粒子，靠的就是這裡看到的「螺線管外部也有感應 E 場」這件事。

🤔 引導問題

因為法拉第定律的積分形式看的是「這個迴路圈住了多少磁通量」，不是「迴路本身所在位置有沒有 B 場」。半徑 r > R 的迴路雖然本身落在沒有 B 場的區域，但它的內部（整個圓面）還是完整圈住了螺線管裡那個正在變化的磁通量 Φ = B(t)·πR²，所以 ∮E·dl = −dΦ/dt ≠ 0，E 場必須存在。

這是初學者最常誤解的地方：誤以為「沒有 B 場的地方就不會有感應 E 場」。正確的理解是：感應 E 場由磁通量的變化率決定，而磁通量是一個「圈住了多少」的整體量，不是逐點對應的。

相同點：兩者用的是同一條方程式（∮E·dl = −dΦ/dt），數學上完全一樣，都是「磁通變化率決定感應效果」。

不同點：模式① 只有一個特定半徑（線圈本身的半徑）才「看得到」感應效果——因為你需要一根導線才能把 EMF 轉成看得到的電流；這裡因為沒有導線的限制，可以看到每一個半徑都有一個 E 值，畫出完整的 E(r) 曲線，而 r = R 只是剛好是「整條曲線的峰值」，不是唯一有感應效果的位置。E 場本身在任何半徑都是真實存在的物理量，不需要導線才「產生」它。

正比增加。E(r=R)_peak = (R/2)·B₀·ω，ω = 2πf，跟模式① 的 EMF_peak = N·A·B₀·ω 是同一種正比關係——把 f 加倍，E(R) 的峰值也剛好加倍。

這再次呼應模式① 的 Q1：時間變化率（dB/dt，正比於 ω）才是決定感應強度的關鍵，跟 B(t) 本身的瞬時大小無關。
