該注意哪裡

端點電流為零。L 增加後，導線上可能出現更多節點，輻射場型也可能多出旁波瓣。

公式

I(z) ∝ sin[k(L/2−|z|)]
F(θ) = [cos((kL/2)cosθ)−cos(kL/2)]/sinθ

引導問題

把 L 從 0.5λ 增到 1.5λ 時，主波瓣會一直變窄，還是會先出現新的瓣？

常見迷思：天線變長不代表每個方向都更強；不同位置的電流會同相相加，也會互相抵消。公式採中心饋入、細導線與正弦電流近似。

近場／遠場：邊界取決於天線尺寸

先設定天線最大尺寸 Dₐₙₜ，再把觀察點移遠；刻度全部用波長 λ 正規化。

工程判準
對數距離軸 · 邊界不是實體牆面電抗近場
場區常用邊界 R1 與 RF 取決於天線最大尺寸 Dₐₙₜ 及波長 λ。
R₁：電抗近場外緣
RF：保守遠場起點

一、設定尺度

2.0 λ
10.0 λ

即時解讀

你現在看什麼

同一支天線周圍可依主要物理行為分區：儲能主導、可能存在的輻射近場，以及輻射場型近似穩定的遠場。

該注意哪裡

D 是天線的最大尺寸。頻率改變會改變 λ，因此同一個公尺距離可能落在不同場區；小天線的中間區通常視為輻射近場／過渡區；大型孔徑才常稱為 菲涅耳區。

公式

R₁=max[0.62√(Dₐₙₜ³/λ), λ/(2π)]
RF=max[2Dₐₙₜ²/λ, 3λ]

引導問題

在大型孔徑、2Dₐₙₜ²/λ 主導時，Dₐₙₜ/λ 加倍會讓 RF/λ 變成幾倍？提示：觀察平方項。

常見迷思：跨過 RF 並不會讓電場突然跳變。這裡以 3λ 作保守教學下限；實際量測仍要看天線型式、環境與所需誤差。

常見迷思：「右旋」或「左旋」須依既定觀察方向定義；本頁重點是同旋相合、反旋正交，不用只靠手勢硬背。

你現在看什麼

每個單元的場在不同方向具有不同路徑相位；AF 是這些相量相加後的正規化結果。

該注意哪裡

N 增加通常讓主波瓣變窄；d 與掃描角一起決定是否出現與主波瓣同高的柵波瓣。

公式

ψ = 2π(d/λ)cosθ + δ
AF = |sin(Nψ/2)/(N sin(ψ/2))|

引導問題

固定 N 與 δ，逐步把 d/λ 拉大；第一個等幅柵波瓣在什麼條件下出現？

常見迷思：d>λ/2 代表「風險增加」，不等於任何相位都一定有柵波瓣。本頁會依 ψ=2πm 的可見解實際判斷。
