峴港・會安口袋旅宿指南｜公開版部署說明

此資料夾已完成純靜態匯出與手機版 QA，可直接部署到 GitHub Pages。

建議公開網址：
https://francis007.github.io/

部署方式：
1. 在 GitHub 建立公開儲存庫，名稱必須是 Francis007.github.io。
2. 將本壓縮檔解壓後的「所有內容」放在儲存庫根目錄。
3. 到 Settings > Pages。
4. Source 選 Deploy from a branch。
5. Branch 選 main，資料夾選 /(root)，按 Save。
6. 等候 GitHub Pages 完成部署後，即可開啟上方網址。

注意：
- 請保留 .nojekyll 與 _next 資料夾。
- 請勿只上傳壓縮檔；必須先解壓。
